# Financial Desk — Финансовый ассистент

Интерактивный веб-инструмент для финансово-экономических расчётов: свод данных из первоисточников, анализ показателей, сравнение сценариев и построение финансовых моделей (ценообразование, точка безубыточности, DCF). Реализован по [PRD](./PRD.md).

Работает полностью на клиенте — без сервера, без сохранения данных между сессиями.

## Разделы

- **Данные** — импорт из Excel/CSV (SheetJS) с сопоставлением статей по ключевым словам, либо ручной ввод P&L и баланса по периодам.
- **Анализ** — KPI-карточки (маржи, рост выручки), графики динамики, таблица коэффициентов (ликвидность, ROE, ROA, долг/капитал).
- **Сценарии** — пессимистичный / базовый / оптимистичный прогноз выручки и прибыли на 1–10 периодов вперёд.
- **Модель** — DCF-калькулятор (NPV, IRR, срок окупаемости) и калькулятор точки безубыточности с графиком.

## Стек

React 18 + Vite, Tailwind CSS (тёмная тема), Recharts, lucide-react, SheetJS (`xlsx`).

## Запуск

```bash
npm install
npm run dev
```

Продакшн-сборка:

```bash
npm run build
npm run preview
```

## Референсный кейс

Кнопка «Загрузить пример» на странице «Данные» подставляет расчёт из PRD (курсы повышения квалификации: себестоимость 50 000 ₸/слушателя, цена 62 000 ₸, постоянные расходы 40 000 ₸/мес, группы 15/18/20 человек).
